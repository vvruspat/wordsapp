- Node 22.23.3: `npm test` — 36/36; сохранены все 15 исходных regression tests.
- `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm run architecture`, `git diff --check` — успешно. Проверка архитектуры охватывает 245 production-модулей.
- Дополнительные временные fixtures вне репозитория: разрешённая композиция, cross-feature alias, relative type import, обратный реэкспорт, dynamic import, UI → route и цикл — все семь проверок дали ожидаемый результат.
- `expo export --platform ios` и `expo export --platform android` — успешно, с генерацией Hermes bytecode.
- Сверены все 23 пути маршрутов и хеши 17 защищённых файлов: схема/миграции/модели БД, app config, EAS config, lockfile и хранение токенов не изменены.
- Graphify обновлён после изменения production-кода; генерируемые графовые файлы не включены в коммиты.

## iOS runtime

Debug development build успешно собран через Xcode для iPhone 18 Pro / iOS 27 Simulator. Финальный JS загружен через Metro. Проверены запуск, начальный экран ввода email, accessibility поля, фокус, email-клавиатура и смещение формы над клавиатурой.

Первая неподписанная локальная сборка не имела entitlement для SecureStore. Проверка повторена с временными simulator entitlements и локальной подписью через параметры xcodebuild; исходная Expo/native-конфигурация проекта не менялась. После этого ошибок SecureStore при старте нет.

Metro сообщает предупреждение об exports пути `expo-router/build/global-state/router-store` и успешно использует файловый fallback. Lockfile и версия Router сохранены. Предупреждение react-test-renderer о deprecated API также не скрывалось.

## Авторизованный iOS smoke — 20 октября

После входа пользователя проверен локальный API и iPhone 18 Pro / iOS 27 Simulator. Воспроизведён пустой экран карточек: learning layout успевал сохранить пустую выборку до первой синхронизации, а после её завершения менеджер её не перечитывал. Исправлен lifecycle пустой выборки в standalone и mixed; активный непустой набор при фоновой синхронизации сохраняется.

Дополнительно исправлены приоритет незавершённых слов, выход из review при смене упражнения, повторное открытие завершённого standalone, размер раунда сопоставления при review, обработка ошибки подготовки mixed с retry и подсчёт mastery в меню по `score > 0`.

Проверено в интерфейсе:

- Все шесть упражнений загружают данные; правильный ответ, обновление счётчиков и следующий шаг.
- Ошибочные ответы в «Да или нет» и вводе слова, показ исправления и продолжение; полный раунд из четырёх сопоставлений.
- Mixed переключает типы упражнений; выбор темы → знакомство с пятью словами → mixed с этими словами.
- Профиль отображает текущую сессию; открываются ситуации, история и завершённый диалог; переход из истории к тренировке слов работает.
- При остановленном локальном API после перезагрузки сохраняется вход, карточки загружаются из локальной БД и записывают результат. Это проверка с действующим access token, а не истёкшим refresh token. API затем запущен снова.

Автоматические проверки: 50/50 тестов; typecheck, lint, format и architecture — успешно. Девять новых regression-сценариев воспроизводят ошибки на предыдущем коде `15109c0`, а после исправлений проходят. Новые проверки используют реальные React effects, Zustand и RxJS с заменой native/database границ; охватывают sync/loading/empty/error/retry, fixed pool, смену языка/отборов, StrictMode, review и счётчики.

## Пределы проверки

Android проверен сборкой JS до этих исправлений, без запуска на устройстве. В iOS проверен авторизованный проход, описанный выше; ответы и знакомства создали локальный учебный прогресс. Вход выполнил пользователь. Выход, смена языков в реальном аккаунте, отправка новых реплик диалога и завершение всего mixed до 100% в интерфейсе не проверялись в этом проходе. Завершение mixed и удаление выполненных упражнений из пула покрыты автоматическими тестами. Фактическое звучание аудио на физическом устройстве не проверялось.

Релиз, merge и публикация приложения не выполнялись.
